1 Setup

Load packages required for data import, cleaning, descriptive analysis, and assessment of inter-coder reliability.

2 Import Data

Import the independently coded datasets completed by SL and MB and the manually assessed free-text agreement dataset.

3 Data Preparation

Binary coding variables were standardized to 1 = Yes and 0 = No. Free-text extraction fields and document metadata were excluded from the binary reliability analysis. Blank, NA, N/A, and placeholder 0 values were treated as missing.

3.1 Data Checks

Confirm that the two coder datasets contain the same coding variables and assess whether document identifiers correspond across datasets.

4 Inter-Coder Reliability

Inter-coder reliability between the two independent coders (SL and MB) was assessed using observed percent agreement and Krippendorff’s alpha. Krippendorff’s alpha was calculated at the nominal level for binary categorical coding variables.

Consistent with the prespecified pilot protocol, the primary reliability assessment pooled eligible document-by-code decisions across all binary codes. An alpha of at least 0.80 was considered sufficient to proceed to the main coding phase.

Variable-level reliability was examined as a secondary diagnostic analysis to identify individual codes associated with disagreement.

5 Free-Text Reliability

Free-text extraction fields were evaluated separately because independently extracted strings could differ lexically while conveying the same substantive information. Agreement was manually assessed based on substantive equivalence.

Document-field pairs in which neither coder entered substantive text were excluded from the substantive agreement denominator.

6 Results

6.1 Overall Inter-Coder Reliability

The reliability analysis included 26 guidance documents and 4,158 eligible binary document-by-code decisions.

Coders agreed on 4,120 coding decisions, corresponding to an overall observed agreement of 99.1%.

Nominal Krippendorff’s alpha across all eligible binary coding decisions was 0.94. The prespecified reliability threshold of alpha >= 0.80 was met.

6.2 Reliability Across Individual Coding Variables

Across the 160 binary coding variables, Krippendorff’s alpha could be estimated for 60 variables. Alpha was not estimable for 100 variables because there was insufficient variation in coder ratings.

Among variables for which alpha was estimable, the median Krippendorff’s alpha was 1.00 (IQR 0.89– 1.00).

Of these, 49 had alpha >= 0.80, 4 had alpha between 0.67 and 0.79, and 7 had alpha < 0.67.
